Function

Function adalah sebuah blok code yang berfungsi untuk menjalankan sebuah tugas yang bersifat spesifik.

Syntax Function

Function syntax adalah aturan penulisan atau format baku untuk membuat sebuah fungsi (function) di dalam bahasa pemrograman.

Alert Function

Alert Function adalah perintah bawaan dalam JavaScript untuk memunculkan jendela pop-up kecil berisi pesan teks dan tombol "OK" di layar.

Return

Return value pada sebuah function adalah nilai yang dikembalikan oleh hasil eksekusi dari kode yang ada di dalam function dan nantinya akan menjadi sebuah output dari function terkait
